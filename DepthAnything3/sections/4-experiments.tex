\subsection{与现有最优方法的比较}

\paragraph{基线方法.}
VGGT~\citep{wang2025vggt} 是一个端到端Transformer，能够从单个或多个视角联合预测相机参数、深度和3D点。Pi3~\citep{wang2025pi3} 进一步采用置换等变设计，从无序图像中恢复仿射不变相机和尺度不变点图。MapAnything~\citep{keetha2025mapanything} 提供了一个前馈框架，也可以将相机位姿作为输入来进行密集几何预测。Fast3R~\citep{yang2025fast3r} 将点图回归扩展到单次前向传播中处理数百甚至数千张图像。最后，DUSt3R~\citep{wang2024dust3r} 通过回归点图并进行全局对齐来处理无标定图像对。我们的方法与VGGT~\citep{wang2025vggt} 类似，但采用了新的架构和不同的相机表示，并且与Pi3~\citep{wang2025pi3} 是正交的。

\paragraph{位姿估计.}
如 \cref{tab:comp_pose} 和 \cref{fig:vis_traj} 所示，与五种基线方法~\citep{dust3r,wang2025vggt,fast3r,wang2025pi3,keetha2025mapanything} 相比，我们的DA3-Giant模型在几乎所有指标上都取得了最佳性能，唯一的例外是DTU数据集上的Auc30。值得注意的是，在Auc3指标上，我们的模型相较于所有竞争方法至少实现了$8\%$的相对改进，在ScanNet++上相较于第二优模型实现了$33\%$的相对提升。

\paragraph{几何估计.}
如 \cref{tab:comp_recon} 所示，
我们的{\giantmodel 在几乎所有场景中建立了新的最优水平，在所有五个无位姿设定下均优于所有竞争对手。平均而言，\giantmodel 相较于VGGT实现了\textbf{25.1\%}的相对改进，相较于Pi3实现了\textbf{21.5\%}的相对改进。\cref{fig:vis_depth} 和 \cref{fig:pcd_vis} 可视化了我们预测的深度和恢复的点云。结果不仅干净、准确、完整，而且保留了精细的几何细节，明显优于其他方法。
更值得注意的是，我们更小的 \largemodel（0.30B参数）展现出显著的效率。
尽管规模小3$\times$，它在十个设定中的五个超越了之前的最优方法VGGT（1.19B参数），在ETH3D上表现尤为出色。

当相机位姿可用时，我们的方法和MapAnything都可以利用它们来改进结果，其他方法也能从真值位姿融合中受益。除7Scenes外，我们的模型在大多数数据集上展现出明显的增益——在7Scenes上，有限的视频设定已经使性能饱和，降低了位姿条件的益处。值得注意的是，在位姿条件下，模型规模扩展带来的性能提升小于无位姿模型，\textbf{这表明位姿估计比深度估计具有更强的规模扩展性，需要更大的模型才能充分实现改进。}

单目深度精度也反映了几何质量。如 \cref{tab:monodepth} 所示，在 \cite{yang2024depthv2} 报告的标准单目深度基准上，我们的模型优于VGGT和Depth Anything 2。作为参考，我们还列出了教师模型的结果。

\paragraph{视觉渲染.}

为了公平评估前馈新视角合成（FF-NVS），我们比较了三个最新的3DGS模型——pixelSplat~\citep{charatan2024pixelsplat}、MVSplat~\citep{chen2024mvsplat} 和 DepthSplat~\citep{xu2025depthsplat}——并进一步通过将我们的几何骨干网络替换为Fast3R~\citep{yang2025fast3r}、MV-DUSt3R~\citep{Mv-dust3r+} 和 VGGT~\citep{wang2025vggt} 来测试替代框架。所有模型在统一的协议下使用DL3DV-10K训练集进行训练，并在我们的基准（\cref{sec:bm_ffnvs}）上进行评估。

如 \cref{tab:ff3dgs_bm_ctx300} 所报告，所有模型在DL3DV上的表现显著优于其他数据集，这表明基于3DGS的NVS对DL3DV标准化的轨迹和位姿分布敏感，而非场景内容。比较两组模型，基于几何模型的框架始终优于专门的前馈模型，这表明简单的骨干网络加DPT预测头可以超越复杂的任务特定设计。这一优势源于大规模预训练，它比依赖极线Transformer、代价体或级联模块的方法具有更好的泛化性和可扩展性。
在这一组中，NVS性能与几何估计能力相关，使DA3成为最强的骨干网络。
展望未来，我们期望FF-NVS可以通过利用预训练几何骨干网络的简单架构得到有效解决，并且DA3强大的空间理解能力将使其他3D视觉任务受益。

\subsubsection{深度-射线表示的充分性}

为了验证我们的深度-射线表示，我们比较了~\cref{tab:ablation_minimal_targets} 中总结的不同预测组合。
所有模型均使用ViT-L骨干网络，相同的训练设置（视角数：10，批大小：128，步数：120k）。
我们评估了四种预测头：1) \textbf{\depth} 用于密集深度图；2) \textbf{\pcd} 用于直接3D点云；3) \textbf{\cam} 用于9自由度相机位姿 $\mathbf{c}=(\mathbf{t}, \mathbf{q}, \mathbf{f})$；以及4) 我们提出的 \textbf{\ray}，预测逐像素射线图（\cref{sec:formulation}）。
\ray 预测头使用Dual-DPT架构，而 \pcd 使用单独的DPT预测头。对于没有 \pcd 的模型，点云通过将 \depth 与来自 \ray 或 \cam 的相机参数结合得到。
如表~\ref{tab:ablation_minimal_targets} 所示，最小的 \depth + \ray 配置在所有数据集和指标上始终优于 \depth + \pcd + \cam 和 \depth + \cam，在Auc3上相对于 \depth + \cam 实现了近100\%的相对增益。
添加辅助 \cam 预测头（\depth + \ray + \cam）没有带来进一步的好处，证实了深度-射线表示的充分性。
我们采用 \depth + \ray + \cam 作为最终表示，因为相机预测头的计算开销可以忽略不计，大约占主骨干网络计算成本的0.1\%。

\subsubsection{单个普通Transformer的充分性}
我们将标准ViT-L骨干网络与VGGT风格的架构进行比较，后者堆叠了两个不同的Transformer，块数是三倍。为了公平比较容量，VGGT风格的模型使用较小的ViT-B骨干网络，其参数量与我们的ViT-L相当。我们的骨干网络支持两种注意力策略：\textbf{Full Alt.}，在所有层中交替使用跨视角/视角内注意力（$L=L_\text{g}$），以及我们的默认部分交替策略。
如表~\ref{tab:abl_dav3} 所示，VGGT风格的模型性能下降到我们基线方法的79.8\%，证实了在相似规模下单Transformer设计的优越性。我们将这一差距归因于我们骨干网络的完全预训练与VGGT中有三分之二的块未经过训练。此外，\textbf{Full Alt.} 变体在几乎所有指标上都有所下降——除了7Scenes上的F1——表明部分交替是更有效且更稳健的策略。

\subsubsection{消融与分析}

\paragraph{双DPT预测头.}
我们通过消融实验评估了双DPT预测头的有效性，其中两个独立的DPT预测头分别预测深度图和射线图。结果报告在 \cref{tab:abl_dav3} 的(d)项中。与配备双DPT预测头的模型相比，无此设计的变体在各个指标上均出现一致下降，证实了我们双DPT设计的有效性。

\paragraph{教师模型监督.}
我们消融了使用教师模型标签作为监督的做法，定量结果报告在 \cref{tab:abl_dav3} 的(e)项中。没有教师标签的训练在DTU上略有改进，但在7Scenes和ScanNet++上导致性能下降。值得注意的是，在HiRoom上退化尤为明显。我们将其归因于HiRoom的合成性质及其真值包含大量精细结构；来自教师的监督帮助学生更准确地捕捉这些细节。\cref{fig:vis_teacher_sup} 中的定性比较证实了这一趋势：使用教师标签监督训练的模型产生的深度图具有更丰富的细节和更精细的结构。

\paragraph{位姿条件.}
为了评估位姿条件模块，我们在ViT-L骨干网络上对其进行消融，结果报告在 \cref{tab:abl_dav3} 的(f)和(g)项中。与表中其他条目不同，这两项是在真值位姿融合下评估的（标有"*"），而其余条目使用预测位姿融合。在各个指标上，带位姿条件的配置始终优于不带位姿条件的配置，证实了位姿条件模块的有效性。

\subsection{Depth Anything 3 度量深度模型分析}

我们与最先进的度量深度估计方法（包括DepthPro~\cite{bochkovskiydepth}、Metric3D v2~\cite{hu2024metric3dv2}、UniDepthv1~\cite{piccinelli2024unidepth} 和 UniDepthv2~\cite{piccinelli2025unidepthv2}）在5个基准上进行比较：NYUv2~\cite{silberman2012nyu}、KITTI~\cite{geiger2013kitti}、ETH3D~\cite{schops2017eth3d}、SUN-RGBD~\cite{song2015sunrgbd} 和 DIODE（室内）~\cite{vasiljevic2019diode}。

如 \cref{tab:metric} 所示，DA3-metric在\textbf{ETH3D上取得了最优性能}（$\delta_1$ = 0.917, AbsRel = 0.104），大幅超过了第二优方法UniDepthv2（$\delta_1$ = 0.863）。DA3-metric还在\textbf{SUN-RGBD上取得了最佳AbsRel}（0.105），并在\textbf{DIODE上取得了第二优}（$\delta_1$ = 0.838, AbsRel = 0.128）。虽然UniDepthv1和UniDepthv2在NYUv2和KITTI上取得了最佳结果，但DA3-metric在所有基准上展示了强大的泛化能力和有竞争力的性能，尤其是在像ETH3D这样多样化的室外场景中表现出色。

我们在 \cref{tab:metric} 中对教师监督进行了消融。结果显示了有趣的权衡：移除教师监督在NYUv2和KITTI上略微提升了指标，而在其他数据集上保持可比的性能。如图~\ref{fig:metric-abl} 所示，教师监督显著改善了清晰度和细节质量，表明教师模型提供了超出标准指标之外的补充知识。

\subsection{前馈3DGS分析}

我们重新训练了所有比较的前馈3DGS模型，通过使用最远点采样选择12个输入上下文视角来确保训练配置与测试设置匹配。我们采用了工程优化，如flash attention和完全共享的数据并行，使所有模型能够高效处理12个输入视角。所有基线均加入深度训练损失以确保稳定训练和收敛。所有模型在8个A100 GPU上训练，步数200K，批大小为1，但pixelSplat由于极线注意力较慢而训练了100K步。所有结果均在 $H \times W = 270 \times 480$ 下报告。

\paragraph{视觉质量分析.}
我们在 \cref{fig:vis_nvs_render} 中展示了在新视角合成设置下与其他模型的视觉比较。如图所示，仅通过在我们的DA3模型上添加一个3D高斯DPT预测头，就能在现有最优方法的基础上显著提升渲染质量。我们的模型在具有挑战性的区域展现出特别强的能力，例如细薄结构（如第一个和第三个场景中的柱子）以及具有宽基线输入视图的大规模室外环境（最后两个场景），如 \cref{fig:vis_nvs_render} 所示。这些结果强调了稳健的几何骨干网络对于高质量视觉渲染的重要性，这与我们在 \cref{tab:ff3dgs_bm_ctx300} 中的定量结果一致。我们预期DA3强大的几何理解能力也将使其他3D视觉任务受益。
