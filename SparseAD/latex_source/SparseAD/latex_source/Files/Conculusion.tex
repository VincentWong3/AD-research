\section{结论与未来工作}
\paragraph{\textbf{结论。}}
本文提出了一种新颖的稀疏查询中心（Sparse Query-Centric）范式用于端到端自动驾驶（命名为SparseAD），将整个驾驶场景的时空信息压缩到稀疏查询中。本文重新审视了自动驾驶任务，设计了由稀疏感知和运动规划器组成的更简洁架构。在具有挑战性的nuScenes数据集上进行的大量实验证明了SparseAD的有效性和优越性。希望SparseAD能够揭示端到端自动驾驶方法在性能、效率和可扩展性方面的巨大潜力。

\paragraph{\textbf{局限性与未来工作。}}

尽管SparseAD显著提升了全栈驾驶任务的性能，如何在优化过程中平衡多个任务仍然值得探索。此外，在稀疏方式下进一步提升在线建图性能是未来潜在的研究方向。
